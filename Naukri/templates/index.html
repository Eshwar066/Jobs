Quick Start Guide

  1. Env tab: Add your GEMINI_API_KEY (or use local LLM with Docker/Ollama).
  2. Config tab: Set role, location, resume_path, max_applications, etc.
  3. Resume Profile tab: Paste JSON profile or run python resume_profile.py --force.
  4. Dashboard tab: Click Start Login, sign in to Naukri, then click Login Successful.
  5. Dashboard tab: Click Start Search to begin applying.

Local LLM Setup

  1. Install Docker Desktop.
  2. Run docker compose up -d (creates ollama container).
  3. Pull a model: docker exec ollama ollama pull llama3.2:1b
  4. In Config, set "llm_provider": "local" and "local_model": "llama3.2:1b".
